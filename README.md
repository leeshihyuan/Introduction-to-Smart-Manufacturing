台積電誕生的靈感

張忠謀從1978年卡弗． 米德(Carver Mead)和琳．康維(Lynn Conway)合著的開創性教科書《VLSI系統導論》（超大型積體電路系統導論） (Introduction to VLSI Systems)汲取靈感，構想出半導體產業的全新商業模式。當時所有半導體公司都同時設計和製造晶片，而本書雖然沒有明確這麼主張，但張忠謀從中領悟到，這樣做是可行的。這個想法將會徹底改寫半導體產業的格局。

── 摘自何貴森《幽影之國》〈第十一章 不可或缺的島嶼〉八旗文化

張忠謀從 VLSI 系統導論一書中，找到創辦台積電靈感的過程，也符合馬斯克工作信奉的第一性原理。

機器人叫獸主編之台灣自編大學教科書系列書籍，是結合其大學教學與小學社團備課教材，以台灣工程教育場景為基礎而編輯的教科書，適合從小學生到大學生入門閱讀，希望達到激發學生實作與更深入學習的效果。

編寫智慧製造導論一書的緣由，是為了紀念機器人叫獸的哲學導師 李登輝前總統，他與濱田宏一教授在2016年合著的日台IoT同盟，加深團隊長久研究第四次產業革命的興趣與動力，也奠定編寫本書的基礎知識。

智慧製造導論的編著特別感謝國立雲林科技大學的長官、智慧科技學院的長官，以及智慧製造學程的長官，因為他們的提攜讓機器人叫獸有難得的機會可以在智慧製造相關領域精進自己的教學能量，是編著智慧製造導論的最關鍵推力。

希望本書能拋磚引玉，產官學各界先進不吝指正。而讀了這些書的台灣學生們，未來也能創辦下一個世代的智慧製造公司。
